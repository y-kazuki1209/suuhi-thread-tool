# 絶対に起きれる目覚まし時計

ブラウザだけで動く「確実に起きる」ための目覚まし時計アプリです。サーバーや外部音源は不要で、`index.html` を開くだけで使えます。

## 使い方

```bash
# ローカルで開くだけでもOK
open alarm-clock/index.html   # macOS
# もしくは簡易サーバーで
npx serve alarm-clock
```

このタブを開いたまま端末をスリープさせないでください（ブラウザの仕様上、バックグラウンドタブや画面ロック中は音が鳴らない場合があります）。

## iPhoneでの使い方

1. `index.html` をホスティングしたURL（GitHub Pagesなど）、またはローカルサーバー（`npx serve alarm-clock` 等）のURLをiPhoneのSafariで開きます。
2. 共有ボタン（□に↑）→「ホーム画面に追加」をタップすると、アイコン付きでアプリのように起動できるようになります（PWA対応、`manifest.json` / `apple-touch-icon` 設定済み）。
3. 確実に鳴らすために、アプリ内にも表示される以下の項目を就寝前に確認してください。
   - 本体側面の**着信/サイレントスイッチ**をオン（音が鳴る側）にする
   - **おやすみモード/集中モード**をオフにするか、このアプリの通知を許可する
   - 設定→「画面表示と明るさ」→「自動ロック」を**「なし」**にする（充電しながら推奨）
   - アプリの画面を開いたままにしておく（バックグラウンドに入れない）
4. アラーム音はWeb Audio APIの出力を`<audio>`要素経由で再生することで、iPhoneのサイレントスイッチの影響を受けにくくしています（iOSの仕様上、完全に保証はできません）。
5. 画面消灯防止にはWake Lock API（iOS 16.4以降のSafariで対応）を使用しています。非対応の場合は手動で自動ロックを無効にしてください。

## 「必ず起きれる」ための工夫

- **止めるには計算問題に正解する必要がある**：アラーム音を止めるボタンを押すと、簡単な計算問題（デフォルト3問）が出題され、全問正解しないと音が止まりません。
- **止めるには「0秒思考」メモを紙に書く必要がある**：計算問題のあとに、赤羽雄二氏の著書『ゼロ秒思考』のメモ書きを促す画面が出ます。本の趣旨どおり**デバイスへの入力ではなく紙に手書き**するフローで、アプリはお題（例：「今日の目標は？」）の提示と「1ページ1分」の目安タイマー(60秒)だけを担当します。タイマーが0:00になるまで「紙に書き終えた」ボタンは押せません。押すとアラームが止まり、内容そのものではなく「いつ・どのお題で書いたか」だけが記録として残ります（アプリ下部の「0秒思考 記録」に、今日と通算の枚数つきで表示）。計算問題・0秒思考メモはそれぞれアラームごとにON/OFF可能で、両方ONの場合は計算問題→0秒思考メモの順に完了する必要があります。前夜に枕元へA4用紙(またはノート)とペンを用意しておくのがおすすめです。
- **スヌーズするほど問題が難化**：スヌーズ回数が増えるほど計算問題の難易度が上がるため、スヌーズを繰り返すより起きて計算した方が楽になります。
- **スヌーズ回数に上限**：アラームごとにスヌーズ可能回数を設定できます（デフォルト3回）。上限に達するとスヌーズできず、計算問題を解くしかなくなります。
- **音量が徐々に大きくなるサイレン音**：Web Audio APIで生成したサイレン音が約25秒かけて音量最大まで上がり続けます（外部音源ファイル不要）。
- **画面点灯を維持（対応端末）**：鳴動中は Wake Lock API で画面スリープを防止します。
- **バックグラウンド通知（対応環境）**：タブが非アクティブな間に鳴った場合、通知でも知らせます。
- **繰り返し設定**：曜日を指定しなければ「次に来るその時刻のタイミングで1回だけ」鳴るアラームになります。曜日を選べば毎週その曜日に繰り返します。
- **端末再起動・リロードしても設定が残る**：アラーム一覧は `localStorage` に保存されます。

## 制限事項

- ブラウザタブを閉じている間はアラームは鳴りません（ネイティブアプリではないため）。iOSのSafari/PWAには「Webページが完全にバックグラウンドで動き続ける仕組み」が無いため、タイマー起動型のアラームはOS標準の目覚まし時計ほどの確実性は保証できません。確実性を最優先するなら、iPhone標準の「時計」アプリのアラームと併用することを強く推奨します。
- 音はWeb Audio APIで生成したサイレン音のみです（好きな音源に差し替えたい場合は `app.js` の `startAlarmSound` を編集してください）。
- iOSのサイレントスイッチ回避は`<audio>`要素経由の再生による best-effort な対策であり、iOSのバージョンや設定によっては音が鳴らない場合があります。
